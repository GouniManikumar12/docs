---
title: "Cost Per Exposure (CPX)"
description: "How AdMesh prices verified visibility in AI conversations"
---

**CPX** is what an advertiser pays when their recommendation is shown in an AI response.

You pay for verified visibility — not page views, cookies, or assumed impressions.

## When CPX is charged

A CPX event fires only when:

1. The recommendation is rendered in the UI
2. The user session is verified as active and unique

## How CPX is set

AdMesh sets CPX from:

1. **Campaign type** — your base CPX, or a rate derived from CPA
2. **CRS** — stronger relevance usually means higher placement and CPX
3. **Competition** — demand in that category or query theme

## CPX vs CPC vs CPA

| Metric | Trigger | Purpose |
|--------|---------|---------|
| **CPX** | Offer is shown | Visibility |
| **CPC** | User clicks | Engagement |
| **CPA** | User converts | Performance |

## Common questions

<AccordionGroup>
  <Accordion title="Is CPX charged if no one clicks?">
    Yes. CPX is for verified visibility, not clicks.
  </Accordion>
  <Accordion title="Can I cap CPX?">
    You set a base CPX or CPA. AdMesh balances exposures within your campaign limits.
  </Accordion>
  <Accordion title="What’s a typical range?">
    Rough ranges: SaaS $0.01–$0.10, e-commerce $0.005–$0.05, services $0.02–$0.20.
  </Accordion>
</AccordionGroup>
