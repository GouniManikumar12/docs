---
title: "AI Platform FAQ"
description: "Answers about SDK setup, ad formats, tracking, and brand conversations."
---

<AccordionGroup>
  <Accordion title="How do I get started?">
    Register, complete platform onboarding, and create an API key in the dashboard.
    Then follow [Getting Started](/platforms/overview) to integrate your selected formats.
  </Accordion>

  <Accordion title="Which SDK do I need?">
    Use `admesh-ui-sdk` for React or `admesh_flutter_ui_sdk` for Flutter.
    Backend Weave SDKs are optional and needed only for the Weave integration.
  </Accordion>

  <Accordion title="What is the difference between Tail, Product, Bridge, and Weave?">
    Tail shows a short recommendation with links below the answer. Product shows
    product cards. Bridge can let the user start a brand-agent conversation.
    Weave places sponsored links inside the assistant's answer.
  </Accordion>

  <Accordion title="How do I add Tail or Product recommendations?">
    Wrap your React chat with `AdMeshProvider` and render `AdMeshRecommendations`
    below assistant responses. Pass the original user query and its user message ID.
    See [Tail &amp; Product Format](/platforms/tail-format).
  </Accordion>

  <Accordion title="Do I set a format on the recommendation component?">
    No format prop is needed on `AdMeshRecommendations`. Select allowed formats
    in the dashboard; the returned recommendation determines the rendered layout.
  </Accordion>

  <Accordion title="Which session and message IDs should I use?">
    Keep one stable `sessionId` per conversation. For `AdMeshRecommendations`, pass
    the original user message ID. For `WeaveAdFormatContainer` and streaming events,
    use the assistant message ID returned by your backend.
  </Accordion>

  <Accordion title="What extra setup does Weave need?">
    Fetch recommendations on your backend before calling your LLM and preserve the
    supplied tracking links in its output. Wrap the rendered response with
    `WeaveAdFormatContainer` and connect streaming events.
    Follow [Weave Ad Format](/platforms/weave-ad-format).
  </Accordion>

  <Accordion title="What do I need for Talk to Agent?">
    Implement consent and activation callbacks, route brand turns through your
    backend, and connect the stop action. The recommendation component alone does
    not provide your brand-conversation runtime. See [Bridge Format](/platforms/bridge-format).
  </Accordion>

  <Accordion title="Do I add exposure and click tracking manually?">
    The UI components handle exposure and click tracking for their supported
    integration paths. Preserve tracking URLs and Ad labels. Conversion tracking
    requires its own applicable setup.
  </Accordion>

  <Accordion title="Why are recommendations not showing?">
    Check your API key, provider, session ID, message ID, and query. An eligible
    recommendation must be returned. For Weave, also check rendered links and
    matching streaming-event IDs.
  </Accordion>

  <Accordion title="How do I test the integration?">
    Verify an eligible recommendation renders and its link works. Test a response
    with no recommendation. For Weave, test woven links and fallback; for Bridge,
    test consent acceptance, decline, and stopping the brand session.
  </Accordion>
</AccordionGroup>
