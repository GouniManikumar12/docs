## 1. Create an account

[Register for AdMesh](https://useadmesh.com/auth/signin/?role=agent&type=get-started&mode=signup).

## 2. Complete onboarding

Add your platform details and select the ad formats you want to use.

## 3. Create an API key

Create an API key in the AdMesh dashboard and use it as `apiKey` in the integration below.

## 4. Install the frontend SDK

```bash
npm install admesh-ui-sdk@latest
```

For Flutter, follow the [Flutter integration steps](/ui-sdk/flutter).

## 5. Wrap your chat with AdMeshProvider

Use your AdMesh API key and keep the same `sessionId` throughout the conversation.

```tsx
import { AdMeshProvider } from 'admesh-ui-sdk';

<AdMeshProvider apiKey={apiKey} sessionId={sessionId}>
  <YourChat />
</AdMeshProvider>
```

## 6. Integrate your selected format

<Tabs>
  <Tab title="Tail, Product & Bridge">
    Add `AdMeshRecommendations` below each assistant response. Pass the original
    user query and its user message ID.

    ```tsx
    import { AdMeshRecommendations } from 'admesh-ui-sdk';

    <AdMeshRecommendations
      messageId={userMessageId}
      query={userQuery}
    />
    ```

    Use the formats selected in your dashboard; no format prop is needed.
    For Bridge's Talk to Agent action, connect the
    [delegation callbacks](/platforms/bridge-format#4-connect-consent-and-activation).

  </Tab>

  <Tab title="Weave (optional)">
    Complete these additional steps only if you selected Weave.

    ### 1. Install a backend SDK

    <CodeGroup>
      ```bash Node.js
      npm install @admesh/weave-node@latest
      ```

      ```bash Python
      pip install admesh-weave-python
      ```
    </CodeGroup>

    ### 2. Fetch recommendations before generating the response

    Follow the [Node.js](/weave-node/installation#quick-start) or
    [Python](/weave-python/installation) setup. Pass the returned recommendation
    context into your LLM and preserve AdMesh tracking links in its output.

    ### 3. Wrap the assistant response

    Use this container in place of the standalone `AdMeshRecommendations` unit
    for the same response. Pass the assistant message ID returned by your backend.

    ```tsx
    import { WeaveAdFormatContainer } from 'admesh-ui-sdk';

    <WeaveAdFormatContainer
      messageId={assistantMessageId}
      query={userQuery}
      fallbackFormat="tail"
    >
      <YourRenderedAssistantResponse />
    </WeaveAdFormatContainer>
    ```

    ### 4. Connect streaming events

    Dispatch these events from your chat's streaming handlers, using the same
    assistant message ID and provider session ID.

    ```tsx
    import {
      dispatchStreamingStartEvent,
      dispatchStreamingCompleteEvent,
    } from 'admesh-ui-sdk';

    // When streaming starts and the assistant message ID is available:
    dispatchStreamingStartEvent(assistantMessageId, sessionId);

    // When streaming finishes and the response has rendered:
    dispatchStreamingCompleteEvent(assistantMessageId, sessionId);
    ```

    When testing, check that woven links receive an Ad label. Test a response
    without woven links to verify fallback recommendations when an eligible ad
    is available.
  </Tab>
</Tabs>

## 7. Test your integration

Open your app and send a query. Verify that an eligible recommendation renders
and that its links work.
