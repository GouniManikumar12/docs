---
title: "Getting Started"
description: "Copy the publisher assistant script from your dashboard and place it on your site."
---

## 1. Copy your install snippet

Open [Publisher Assistant](https://useadmesh.com/dashboard/agent/publisher-assistant-setup)
in your AdMesh dashboard and select **Deployment**. Complete any setup items shown
there until the install snippets are ready to copy.

## 2. Choose where the assistant appears

Copy **Add assistant container** into your page's HTML where you want the
assistant to appear, such as below an article or inside a sidebar.

```html
<div id="admesh-publisher-assistant"></div>
```

Use the container ID from your dashboard. It must match the script's
`data-target-selector`.

## 3. Add your script

Copy **Add script before closing body tag** from the dashboard. Paste it after the
container, before `</body>`. Keep the publisher identifier supplied in your snippet.

This example shows the structure; use your own dashboard-generated script:

```html
<div id="admesh-publisher-assistant"></div>
<script
  src="https://embed.useadmesh.com/publisher-assistant.js"
  data-agent-display-id="YOUR_AGENT_DISPLAY_ID"
  data-mode="inline"
  data-suggestion-style="carousel"
  data-target-selector="#admesh-publisher-assistant"
  async
></script>
```

In a CMS, use a Custom HTML block for the container and a script/footer code field
for the script. The page must allow JavaScript to run.

## 4. Add the monetization entry

Copy the **ads.txt** line provided in Deployment into your site's `/ads.txt` file
before enabling monetization.

## 5. Test

Publish the page, confirm the assistant appears in the chosen container, and ask
a question. Open and minimize the conversation to check both layouts.

If it does not appear, check that the container exists before the script runs,
the selector matches, and the assistant is enabled in the dashboard. Also check
page, device, and country restrictions.

Use [Customize](/publishers/controls) to customize the assistant.
